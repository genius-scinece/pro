2. 配信面と自動化可否(2026年時点の事実整理)
════════════════════════════════════════
┌─────────────────┬──────────────┬────────────────────────────┐
│ 配信面            │ 自動化       │ 方法                        │
├─────────────────┼──────────────┼────────────────────────────┤
│ Facebookページ    │ ◎ 完全自動化 │ Meta Graph API / 予約ツール │
│ Facebookグループ  │ △ 半自動     │ ※API廃止(2024/4)のため      │
│                   │              │ ページ投稿→手動シェア1クリック│
│ Instagramリール   │ ◎ 完全自動化 │ Meta Graph API / 予約ツール │
│ TikTok            │ ◎ 完全自動化 │ Content Posting API /       │
│                   │              │ 予約ツール or ネイティブ予約 │
│ YouTubeショート   │ ◎ 完全自動化 │ YouTube Data API /          │
│                   │              │ Studioのネイティブ予約       │
└─────────────────┴──────────────┴────────────────────────────┘
重要: FBグループはMeta社がAPIを廃止したため、世界中のどのツールでも
完全自動投稿はできません。「ページに自動投稿→グループへ共有ボタン」の
1クリック運用(1日30秒)が現実的な最短手順です。

3. 基本アーキテクチャ「1動画5面展開」
════════════════════════════════════════
  1本の30秒縦動画(9:16)を作り、同日に5面へ展開する。

  [コンテンツバンク(Google Sheets)]
        │ 台本・キャプション・ハッシュタグ・ステータス管理
        ▼
  [動画制作] CapCutテンプレ or AI動画(HeyGen等・AI講師キャラ)
        │ 完成動画をGoogle Driveの「approved」フォルダへ
        ▼
  [承認ゲート] 運営がシートのstatusを draft → approved に変更 ★人
        ▼
  [予約投稿ツール] FBページ・IG・TikTok・YTショートへ自動配信
        ▼
  [FBグループ] ページ投稿を手動シェア(1クリック) ★人

4. 段階導入プラン
════════════════════════════════════════
Phase 1(今週から・費用0):
  ・コンテンツバンク(付属CSV)をGoogle Sheetsに取り込み
  ・動画第1弾10本を制作(台本は reel-scripts-batch1.txt)
  ・Meta Business Suite(無料)でFBページ+IGを予約投稿
  ・TikTokはアプリ内予約、YouTube Studioでショート予約
  → ツール2つ+手動シェアで、実質「週1回まとめて仕込み」体制に。

Phase 2(1〜2ヶ月目・月$20前後):
  ・一元管理ツールを1つ導入(推奨: Metricool / Buffer / Postiz)
  ・4面すべてを1画面から予約。CSVカレンダーを一括インポート。
  ・分析(どの柱が伸びるか)を毎週確認し、配信比率を調整。

Phase 3(3ヶ月目〜・完全自動化):
  ・n8n(またはMake.com)でパイプライン構築:
    シートに台本追加 → AIが動画生成 → Driveに保存 →
    status=approved を検知 → 各APIへ自動投稿 → 結果をシートに記録
  ・承認ゲート(approved列)は必ず残す。人が見ていない投稿は流さない。
  ・必要なAPI: Meta(FBページ/IG)、TikTok Content Posting API(審査要)、
    YouTube Data API(OAuth)。アカウント連携・API申請は人の作業。

5. 週次運用ルーチン(Phase 1〜2)
════════════════════════════════════════
月曜(60分): 翌週分の台本5本をシートで確認・承認(status=approved)
火曜(90分): 動画5本制作(CapCutテンプレ使い回しで1本15分目標)
水曜(30分): 予約ツールに5本×4面をセット
毎日(30秒): FBページ投稿をグループへシェア
金曜(15分): 数値確認(再生数・保存数・プロフィール遷移)→翌週の柱配分を調整

════════════════════════════════════════
6. 承認フロー(このプロジェクトの標準)
════════════════════════════════════════
  台本作成(AI/編集者) → 運営レビュー → status=approved →
  動画制作 → 最終確認 → 予約投稿。
  statusの定義: draft(下書き) / review(確認待ち) / approved(承認済) /
  scheduled(予約済) / posted(配信済) / hold(保留)
