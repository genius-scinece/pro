# 無料で回せる投稿運用システム

> 目標: 月額コスト0円(ドメイン代を除く)で、Facebook / TikTok / Instagram / Zalo への定期投稿を、週1回の「まとめ作業」だけで回せる状態にする。

---

## 1. 使用ツール(すべて無料枠)

| ツール | 用途 | 無料枠の範囲 |
|---|---|---|
| **Meta Business Suite** | Facebookページ+Instagramの予約投稿・分析 | 完全無料・予約数無制限 |
| **TikTok(Web版)** | TikTokの予約投稿(最大10日先まで) | 無料 |
| **Zalo Official Account** | Zaloでの配信 | 無料枠あり(配信数制限あり。開設時に現行条件を確認) |
| **CapCut** | 動画編集・自動字幕 | 無料版で十分 |
| **Canva 無料版** | サムネ・図解・投稿画像 | 無料版で十分 |
| **Googleスプレッドシート** | コンテンツカレンダー(下記テンプレ) | 無料 |
| **Googleドライブ** | 素材(写真・動画・同意書)の保管 | 15GBまで無料 |

> Buffer等のサードパーティ予約ツールは不要。Meta Business SuiteとTikTok公式の予約機能だけで足りる(ツールを増やすほど無料枠の制限に縛られる)。

---

## 2. コンテンツカレンダー(スプレッドシート構成)

シート1「カレンダー」の列構成:

| 列 | 内容 |
|---|---|
| A: 投稿日 | 例 2026-08-03 |
| B: チャネル | FB / TikTok / IG / Zalo |
| C: 柱 | ①想い ②金融教育 ③詐欺対策 ④活動レポート |
| D: タイトル | 例「給料日にまずやること」 |
| E: 本文/台本リンク | Googleドキュメントへのリンク |
| F: 素材リンク | ドライブの動画・画像 |
| G: ステータス | 案 → 制作中 → 予約済み → 公開済み |
| H: 事実確認 | 数字・固有名詞の裏付け確認者のサイン欄 |
| I: 同意確認 | 人物が写る場合の同意書リンク |

シート2「ネタ帳」: 思いついたネタを柱別にストックする場所。

**H列(事実確認)とI列(同意確認)が空欄の投稿は予約しない**、を鉄のルールにする。

---

## 3. 週次運用フロー(合計 約4〜5時間/週)

```
日曜(2〜3時間): バッチ制作日
 ├─ ネタ帳から今週の5〜7本を選ぶ
 ├─ 動画2〜3本をCapCutでまとめて編集
 ├─ 画像投稿をCanvaでまとめて作成
 └─ カレンダーのE/F列を埋める

月曜(1時間): 予約日
 ├─ Meta Business SuiteでFB/IGの1週間分を予約
 ├─ TikTok Web版で予約(10日先まで可)
 └─ Zalo配信文を準備(週1〜2本)

毎日(15分): エンゲージメント
 ├─ コメント返信(ベトナム語。翻訳ツール併用可)
 ├─ 投資勧誘・スパムコメントの削除とブロック
 └─ 良い質問をネタ帳にメモ

月末(1時間): 振り返り
 ├─ Meta Business Suiteのインサイトで上位/下位投稿を確認
 ├─ 伸びた型を翌月の制作に反映
 └─ LPに月次活動レポートを1本追加
```

## 4. 1週間の投稿スケジュール雛形

| 曜日 | TikTok/Reels | 内容 |
|---|---|---|
| 月 | FB投稿 | ④活動レポート(写真+長文) — 週の信頼の土台 |
| 火 | TikTok+Reels | ②「1分のお金の授業」 |
| 水 | — | (エンゲージメントのみ) |
| 木 | TikTok+Reels | ③「その話、詐欺かもしれません」 |
| 金 | FB投稿 | ②図解画像(お金の考え方)or ①想いの投稿 |
| 土 | TikTok+Reels | ④活動ショート or ①想いショート |
| 日 | Zalo配信 | 今週のまとめ+イベント案内(週1) |

TikTokに投稿した動画はすべてReelsに転載(CapCutからロゴなしでエクスポートすること。TikTokの透かし入り動画はReelsでリーチが下がる)。

## 5. コメント・DM対応ポリシー(定型文)

**「投資を教えてほしい」「どこに投資すればいい?」と聞かれたら**(必ず来る質問):

> VN: "Cảm ơn bạn đã tin tưởng! Chúng tôi không giới thiệu bất kỳ sản phẩm đầu tư nào và không nhận tư vấn đầu tư cá nhân. Kênh này chỉ chia sẻ kiến thức quản lý tiền cơ bản. Hãy bắt đầu từ video về quỹ khẩn cấp nhé!"
> (JP訳: 信頼ありがとうございます。私たちはいかなる投資商品も紹介せず、個別の投資相談も受けていません。このチャンネルは基本的なお金の管理知識の共有のみです。まずは緊急資金の動画からどうぞ!)

**運営を名乗る偽アカウント・なりすましへの注意喚起**を固定投稿に含める(このジャンルでは高確率で発生する)。

## 6. 素材管理(Googleドライブ構成)

```
📁 VN-Media/
 ├─ 📁 01_撮影素材/2026-08_孤児院訪問/ ...(日付+場所で整理)
 ├─ 📁 02_完成動画/
 ├─ 📁 03_画像・図解/
 ├─ 📁 04_同意書/(写真掲載同意。施設別に保管)
 ├─ 📁 05_裏付け資料/(領収書・活動記録。公開する数字の根拠)
 └─ 📄 コンテンツカレンダー(スプレッドシート)
```

## 7. 立ち上げ時の初期設定チェックリスト

- [ ] Facebookページ開設 → プロフィール・カバー・自己紹介文(LP文面案から流用)
- [ ] InstagramをFacebookページに連携(Meta Business Suiteで一元管理)
- [ ] TikTokビジネスアカウント化(予約投稿・分析が使えるようになる)
- [ ] Zalo Official Account申請(審査に日数がかかるため早めに)
- [ ] 全チャネルのプロフィールにLPのURLを設置
- [ ] 2段階認証を全アカウントに設定、認証情報は発起人と管理者で共有管理
- [ ] 固定投稿: ①ブランドフィルム ②「私たちは投資勧誘を行いません」の宣言+なりすまし注意
