## 運用上の大原則

1. 本活動は特定の金融商品・投資サービスへの勧誘・誘導を行わない(将来の事業は法律専門家の適法性確認後に別途設計)
2. 公開する数字・実績はすべて写真・証憑で裏付けられるものに限る
3. 人物(特に子ども)が写る素材は書面同意を得たもののみ使用する
4. 「確実に儲かる」等の成果保証表現は一般論としても使用しない

## 次のステップ(人間側の決定事項)

- ブランド名の決定(候補は01の1.3節)
- 発起人の公開プロフィール範囲の決定
- 過去の活動記録・写真・証憑の整理と掲載同意の取得
- 外国人による慈善活動・イベント開催の届出要否を現地専門家に確認
