# 第4講　SNSアカウント設計と設定

> **第4講を終えると**：検証と参入の土台になるSNSアカウント一式が、正しく設計・設定された状態になります。成果物は**SNSアカウント設計・設定シート**と、実際に開設・整備された各アカウントです。
>
> 第3講で作った「刺さる仮説」を、次の第5講で市場にぶつけます。しかし、ぶつける前に**土俵を作る**必要があります。それがこの講です。

---

## 1. なぜ「テストの前」にアカウント設計をやるのか

第3講まででローカライズの仮説ができました。多くの人はここから、すぐに広告を回したくなります。しかし、その前に必ずやるべきことがあります。**SNSアカウントの設計と設定**です。

理由は、ベトナム市場の「信頼」の仕組みにあります。序章と第3講で見たとおり、ベトナムの消費者は警戒心が強い。彼らは広告を見て興味を持つと、**必ずアカウントのプロフィールと過去の投稿を見に行きます**。そのとき——

- プロフィールが空っぽ
- 投稿がゼロ、または広告だけ
- 連絡先がない、返信がこない

——こういうアカウントは、その瞬間に「怪しい外国業者」と判定されます。**どんなに広告のクリエイティブが良くても、着地したアカウントが貧弱なら、そこで信頼は崩れる。** つまり、アカウントが整っていない状態でテストを回すと、「訴求が悪かったのか、アカウントが貧弱だったのか」が区別できず、テスト結果そのものが汚れます。

だから順番はこうです。**アカウントを整える（第4講）→ その上でテストを回す（第5講）。** 土俵を作ってから、勝負する。

この講は4つのステップです。

1. どのアカウントを作るか決める（プラットフォーム選定）
2. 各アカウントを「信頼される」形に設計する（プロフィール設計）
3. テスト開始前に最低限の中身を入れる（コンテンツの初期設計）
4. 受け皿と問い合わせ導線を作る（フォーム・Zalo）

---

## 2. ステップ1：戦場を知る——プラットフォーム別の役割

ベトナムのSNS環境は日本と勢力図が違います。主要なものを、それぞれの「役割」で理解してください。全部に手を出す必要はありません。役割を知った上で、検証フェーズでは**主戦場を2つ**に絞ります。

### Facebook——最大の生活インフラ
ベトナムのFacebookは日本のそれとは別物です。**ほぼ全世代が使う生活インフラ**であり、ニュースも口コミも売買もFacebook上で起きます。個人商店はホームページの代わりにFacebookページを持ち、コミュニティ（グループ）の口コミが購買を左右します。
- 役割：**広告の主戦場**。詳細なターゲティング、リード獲得（予約リスト集め）、コミュニティでの口コミ
- 在越日本人向けなら：日本人コミュニティのFacebookグループが最重要チャネル

### TikTok——発見と爆発の場
若年層〜30代に強く、**「知らなかったものと出会う場所」**。アルゴリズムがフォロワー数に関係なく良い動画を拡散させるため、無名の新規参入者に最大のチャンスがあります。TikTok Shopの浸透でEC送客力も強い。
- 役割：**認知の獲得、顔出しでの信頼づくり**、商品・体験の「映える瞬間」の露出
- 特徴：作り込んだ広告より、**素人っぽい本物感のある動画**が勝ちやすい

### Instagram——都市部・所得高めの層
FacebookやTikTokほどの規模はありませんが、都市部の中間層以上・美容やライフスタイル感度の高い層が濃い。
- 役割：ブランドの世界観提示、高単価商品の信頼形成

### Zalo——クロージングとリピートの場
ベトナムの国民的メッセージアプリ（LINEに相当）。広告よりも、**問い合わせ対応・予約確認・リピート顧客との関係維持**に使います。「広告で興味を持った人がZaloで質問→予約」がベトナムの標準動線です。
- 役割：**受け皿・クロージング・顧客との継続的な関係**

**主戦場の決め方**：TikTokで見つけてもらい、Facebook/Instagramで信頼を作り、広告でリストを集め、Zaloで会話して予約に落とす——これが基本形です。検証フェーズでは、この中から**発信2つ＋受け皿（Zalo/Messenger）**に絞ります。多くの場合、**TikTok（発見）＋Facebook（広告と受け皿）**の組み合わせが出発点になります。

## 3. ステップ2：アカウントを「信頼される形」に設計する

主戦場が決まったら、各アカウントを設計します。ここで効いてくるのが、第3講のローカライズです。**アカウントそのものが、あなたの最初の広告**だと考えてください。

### 個人アカウントとビジネスアカウントの使い分け

- **Facebook**：個人プロフィールとは別に、**Facebookページ（ビジネス用）**を必ず作る。広告出稿・リード獲得はページから行う
- **Instagram**：プロアカウント（ビジネス/クリエイター）に切り替える。インサイト（分析）と広告出稿に必要
- **TikTok**：ビジネスアカウントに切り替える。ただし「素人感」が武器なので、見た目は作り込みすぎない
- **広告出稿の器**：Facebook/Instagram広告は**Meta Business Suite（ビジネスマネージャ）**から出す。ここで広告アカウントを作り、支払い方法を登録する。**この広告アカウントの管理者権限は必ず自分（自社）が保持**します（第6講で外注する際、ここを手放すとアカウントごと失う事故が起きます）

### プロフィール設計の要素

各アカウントで、次の要素を「信頼される形」に設計します。第3講の「日本人向け／ベトナム人向け」の訴求を、ここで反映させます。

| 要素 | 設計のポイント |
|------|--------------|
| アカウント名 | 覚えやすく、事業内容が伝わる。ベトナム語表記＋ローマ字を検討 |
| プロフィール画像 | ロゴまたは「顔」。ベトナムでは**人の顔**が信頼を生む |
| カバー画像 | 「誰の・何を・100%約束できる結果」が一目で伝わるバナー |
| 自己紹介文（bio） | 抽象語を捨て、数字と証拠（第3講）。連絡手段を明記 |
| 連絡先 | Zalo・電話・Messengerを必ず。「連絡できる」こと自体が信頼 |
| 実在の証明 | 日本人技術者の顔、実店舗や実績の写真、資格など（第3講のペルソナ懸念への回答） |

### 日本人向け／ベトナム人向けをどう持つか

第1講で「二段構え」（在越日本人で足場→ベトナム人市場へ）を選んだ人は、アカウントを分けるか統合するかを決めます。
- **分ける**：ベトナム語アカウントと日本語アカウントを別に持つ。訴求を最適化できるが、運用負荷は2倍
- **統合する**：1アカウントで二言語併記。手間は少ないが、どっちつかずになりやすい
- **推奨**：検証フェーズは**メイン市場のアカウント1本に集中**し、もう片方は最小限（プロフィールだけ用意）。テスト結果を見て、本命が定まってから広げる

## 4. ステップ3：テスト開始前の「中身」を用意する

空っぽのアカウントで広告を回してはいけません。広告で来た人が見て「ちゃんと活動している」と感じる最低限の中身を、テスト開始前に入れます。**完璧なコンテンツは不要**です。「実在して、活動している」ことが伝わればいい。

**テスト開始前に最低限そろえるもの（目安）**
- 投稿：各アカウントに**3〜9本**。内訳の目安は「①自己紹介・想い」「②商品・体験の紹介」「③お客様の声や実績、または日本での実績」「④よくある疑問への回答（第2講の"疑い"に答える）」
- ハイライト／固定投稿：一番伝えたいこと（100%約束できる結果）を最上部に固定
- プロフィールの完成：ステップ2の全要素を埋める

これは「投稿の型（コンテンツの柱）」を決めておくと、テスト中・参入後もラクになります。柱の例：**実績・信頼系／体験・映え系／教育・お役立ち系／お客様の声系**。第5講でテストする訴求も、この柱の上に乗せていきます。

> **AIプロンプト⑧：SNSアカウント設計**
>
> ```
> あなたはベトナム市場のSNSマーケティングの専門家です。
> 以下の商品について、検証フェーズを始める前のSNSアカウントを
> 設計してください。
>
> ■ 入口商品設計書（第2講）：【貼り付け】
> ■ ローカライズ設計シート（第3講）：【貼り付け】
> ■ 主戦場にするプラットフォーム：【例：TikTok＋Facebook】
> ■ 狙う市場：【ベトナム人／在越日本人／二段構え】
>
> 各プラットフォームについて、以下を提案してください。
> 1. アカウント名の案（3つ。ベトナム語表記＋読み方）
> 2. 自己紹介文（bio）の文案（ベトナム語＋日本語訳。数字と証拠で）
> 3. カバー画像に入れるコピーと要素
> 4. 固定/ハイライトに置くべき情報
> 5. テスト開始前に投稿する初期コンテンツ3〜9本の案
>    （タイトルと1行の内容。第2講の"顧客の疑い"に答えるものを含める）
> 6. 「信頼される」ために各プロフィールに必ず入れるべき実在の証明
> ```

> **AIプロンプト⑨：初期投稿の台本・文案**
>
> ```
> 上のアカウント設計のうち、初期投稿【本数】本の実際の中身を
> 作ってください。
> - TikTok動画は30秒台本（冒頭3秒のフック→本編→締め）
> - Facebook/Instagram投稿は本文＋ハッシュタグ案
> - ベトナム語は都市部の20〜40代に自然な口語で。日本語訳を併記
> - 各投稿の「この投稿で信頼してもらう狙い」を1行添える
> ```

**ベトナム語は必ずネイティブチェックを。** AIのベトナム語は実用レベルですが、プロフィールや投稿として出す前に、ネイティブ1人のチェックを挟んでください（クラウドソーシング等で数千円）。不自然なベトナム語のアカウントは、それ自体が「怪しい外国業者」のシグナルになります。

## 5. ステップ4：受け皿と問い合わせ導線を作る

広告をクリックした人・投稿を見た人が「行動」できる着地点を用意します。ここが無いと、第5講で「行動」を測れません。

- **リード獲得フォーム**：Facebookのリード獲得広告のフォーム、またはGoogleフォーム。項目は**最小限**に（名前・連絡先・希望日程程度。項目が多いと離脱します）
- **問い合わせ窓口**：**Zaloアカウント（またはFacebook Messenger）**を必ず用意。ベトナムでは「広告→メッセージで質問→予約」が標準動線
- **初回応答文（テンプレ）**：問い合わせに即返信できるよう、あいさつ・料金・予約方法・「強引な勧誘はしない」旨を含むテンプレを準備しておく

検証フェーズでは、立派なホームページは不要です。**Facebookページ＋フォーム＋Zalo窓口**で十分に「行動」が測れます。

## 7. 佐藤さんの例

佐藤さん（日本式フェイシャル）のSNSアカウント設計を見てみましょう。第3講のペルソナ・レビューで出た「日本人が本当にいる証拠が見たい」という最大の懸念が、アカウント設計の中心テーマになりました。

**主戦場**：TikTok（発見・顔出しの信頼）＋Facebook（広告と受け皿）。Zaloを問い合わせ窓口に。Instagramはプロフィールだけ用意して後回し。

**TikTokアカウント**
- 名前：`Tokyo Facial · Cô Sato（サトウ先生）`——人名を出して「実在する日本人」を前面に
- bio：「東京で15年・6万回の施術／銀座と同じ32手順を、ホーチミンで。予約はZalo→」
- 初期投稿6本：①佐藤先生の自己紹介（顔出し・なぜベトナムへ）②「日本のサロンの1日」③32手順のうち3手順の実演 ④「安いサロンで肌荒れした人へ」（疑いに回答）⑤使用化粧品が日本正規品である証明 ⑥お客様（在越日本人モニター）の声

**Facebookページ**
- カバー：「Da đẹp chuẩn Nhật（日本基準の美肌）／日本人技術者が担当／満足できなければ全額返金」
- 実在の証明：佐藤先生の顔写真、日本の店舗の写真、化粧品のロット番号がわかる写真

**受け皿**：リード獲得フォームは「名前・電話・希望日」の3項目のみ（第5講のテストで「フォーム項目が多いと離脱」が判明する前だが、最初から最小限にしていた）。Zaloの初回応答文に「強引な勧誘は一切しません」を明記。

**ネイティブチェック**：ベトナム人スタッフ候補1名に、TikTokのbioと初期投稿の字幕をチェックしてもらい、「先生」のニュアンス（ベトナムでは"cô"が親しみと敬意を両立）を調整。

このアカウントが整ったことで、次の第5講のテストは「訴求の良し悪し」だけをきれいに測れる状態になりました。

## 8. 第4講のまとめ

- ベトナムの消費者は広告を見たら**必ずアカウントを見に行く**。空のアカウントは信頼を壊す
- だから**テストの前に土俵（アカウント）を整える**。順番を逆にすると、テスト結果が汚れる
- プラットフォームは役割で理解する：**Facebook（広告と受け皿）／TikTok（発見と信頼）／Instagram（世界観）／Zalo（クロージング）**。検証は発信2つ＋受け皿に絞る
- アカウントそのものが最初の広告。**プロフィールと初期投稿に「実在の証明」と第3講の訴求**を反映する
- 広告アカウントの**管理者権限は自社が保持**。ベトナム語は**必ずネイティブチェック**

**▸ 第4講終了：検証と参入の土台になるSNSアカウント一式が整った**

土俵ができました。いよいよ次の第5講で、第3講の仮説をこの土俵の上でぶつけ、行動データで検証します。
