> **第6講を終えると**：ABテスト結果を読み解き、「これで行ける」を判断し、**確定戦略書**と**デジタルマーケのプロへの依頼書**が完成します。あわせて、法人化のタイミング・お金と決済の実務・役割分担を設計し、**現場を知るプロとの壁打ち**で戦略の精度を最終確認します。

## 1. データは集まった。さて、どう読むか

第5講の検証フェーズを走らせると、手元に数字とコメントの山ができます。ここからが経営者の仕事です。データの読み方には順番があります。

### 読み方の順番：定量 → 定性 → 矛盾

**ステップ1：定量——勝ち負けをはっきりさせる**
テストごとに、A案とB案の指標（CTR・CPL・登録率・保存率）を並べます。見るのは絶対値より**差**です。差が1.5倍以上ついていれば、市場の意思表示と見なしてよい水準です。差が僅差（1.2倍未満）なら「引き分け」と記録し、その変数は勝敗を決める要因ではなかったと考えます。

**ステップ2：定性——コメントと質問を読み込む**
数字より雄弁なのが、広告やKOC投稿に付いたコメント、Zalo/Messengerに来た質問です。次の3分類で仕分けてください。

- **期待型**：「どこでやってるの?」「予約したい」「いくら?」→ 買う直前の人の声。**多いほど本物の需要**
- **疑い型**：「本当に日本人がやるの?」「写真は本物?」→ 信頼の障壁がまだ残っている証拠。**障壁の中身が具体的にわかる宝の山**
- **無関心型**：スタンプだけ、関係ない話 → ターゲティングのズレの兆候

**ステップ3：矛盾を探す——一番大事な工程**
「CTRは高いのに登録率が低い」→ 広告は魅力的だが、受け皿か価格で失速している。「保存は多いのに問い合わせがない」→ 興味はあるが、行動する理由（今買う理由）が弱い。**矛盾はすべて、直すべき場所を指し示しています。**

> **AIプロンプト⑫：テスト結果の分析**
>
> ```
> あなたはデジタルマーケティングのデータ分析の専門家です。
> ベトナム市場での参入前ABテストの結果を分析してください。
>
> ■ テスト設計：【第5講のABテスト設計書を貼り付け】
> ■ 定量結果：【各案のインプレッション・CTR・CPL・登録数などを貼り付け】
> ■ 定性データ：【代表的なコメント・質問を20件ほど貼り付け】
>
> 以下を出力してください。
> 1. テストごとの勝敗判定と、その確からしさ（差の大きさから）
> 2. コメントの3分類（期待型／疑い型／無関心型）と、それぞれの示唆
> 3. 定量と定性の「矛盾」の指摘と、考えられる原因
> 4. 検証した仮説それぞれについて「支持された/棄却された/判定不能」
> 5. もう1サイクル回すとしたら、次に検証すべきこと
> ```

## 2. 大前提——AIの「当たる」も、テストの「当たった」も、100%ではない

判断に入る前に、どうしても伝えておきたいことがあります。

このマニュアルでは、第1講からずっとAIを壁打ち相手に使ってきました。AIは「この訴求は当たりそうです」と自信たっぷりに答えてくれます。第5講のテストでも、ある案が「勝った」という数字が出ます。しかし——

**AIが「当たる」と言っても、テストで「当たった」数字が出ても、それが実際の市場で100%通用する保証はどこにもありません。**

AIは膨大な知識から「もっともらしい仮説」を出す道具であって、ホーチミンの今この瞬間の消費者の気分を知っているわけではありません。テストの数字も、あくまで「広告に対する反応」であって、「実際にお金を払い続けてくれるか」とは別物です。数百人の反応が良くても、いざ店を開けたら足を運ぶ人は想像より少なかった——そういうことは、現実に起こります。

では、なぜこんなに手間をかけて検証してきたのか。**確実に当てるためではありません。外したときの傷を、致命傷にしないためです。**

### 痛手の非対称性——これがこのマニュアルの心臓部です

同じ「読みが外れた」でも、外れる場所によって傷の深さがまるで違います。

| 外れ方 | 失うもの | ダメージ |
|--------|---------|---------|
| **オンライン検証で外れた**（第5講で「当たらなかった」） | 広告費 数万〜数十万円と、数週間の時間 | 🩹 かすり傷 |
| **リアルで先走って外れた**（法人設立・店舗契約・雇用の後に気づいた） | 設立費用・保証金・賃料・人件費・撤退コスト。数百万〜 | 🩸 大出血 |

序章で「多くの日本人経営者が、整える前に虎に乗って失敗してきた」と書きました。彼らの傷が深かったのは、能力が足りなかったからではありません。**外れたことに気づいた場所が、法人と店舗を作った"後"だった**からです。

あなたはいま、**法人も店舗も持たずに**市場の反応を見ています。もしここで「当たらなかった」なら、それは失敗ではありません。**「数万円と数週間で、致命傷を回避できた」という成功**です。視察旅行で「イケそう」と感じて出店し、半年後に数百万円を失って気づく——その未来を、あなたはお金をかけて先に潰したのです。

だから、この後のNO-GO判定を恐れないでください。オンラインで「ダメだ」とわかることは、このマニュアルの設計が正しく働いた証拠です。

## 3. 「これで行ける」の判断基準

分析ができたら、決断です。基準を先に決めておかないと、人間は都合よくデータを解釈します（お金と時間を使った後は特に）。以下の3段階で判定してください。

### 🟢 GO——参入準備に進んでよい状態
次の**すべて**を満たす：
- 少なくとも1つの訴求で、合格ライン（第5講で設定したCTR・CPL・登録率）をクリアした
- **期待型コメントが疑い型を上回った**、または疑い型の障壁に打ち手が見えている
- 登録者（見込み客リスト）が実在し、その獲得単価で採算シミュレーションが成り立つ
- 自分自身が「この客層と5年付き合いたい」と思えている

### 🟡 PIVOT——筋は良いが、狙いを変えてもう1サイクル
- 数字は合格ラインに届かないが、特定の層・特定の訴求にだけ強い反応がある
- 想定と違う客層（例：狙いは中間層だったが富裕層が反応／ベトナム人狙いだったが在越日本人が反応）から反応が来ている
- → **反応があった方向に仮説を書き換えて、第3講〜第5講をもう1周**。このループは失敗ではなく、検証フェーズの正常動作です

### 🔴 NO-GO——このテーマは見送り。でも、それでいい
- 2サイクル回しても、どの訴求もどの層も合格ラインに届かない
- 期待型コメントがほぼ付かない
- → **ここでやめられることこそ、このマニュアルの最大の価値**です（第2節の「痛手の非対称性」）。失ったのは広告費と数週間だけ。法人・店舗を作ってから気づく場合の、数十分の一の授業料です

**NO-GOは終わりではなく、第1講に戻る合図です。**

「このテーマはベトナムに合わなかった」——それがわかっただけで、あなたは一つ賢くなりました。次にやることは決まっています。**第1講に戻ってください。** 自分の資産の棚卸し（第1講のワーク）をもう一度眺め、「これもいけるかもしれない」と思える別のテーマを選び、第2講→第3講→第4講→第5講と、同じ手順でまた検証する。

このマニュアルは、一度きりの正解を出す道具ではありません。**「いけるかも」と思ったことを、致命傷を負わずに何度でも試せる仕組み**です。1つ目で当たれば幸運。2つ目、3つ目で当たるのが普通です。そして何度試しても、あなたが失うのは毎回「広告費と数週間」だけ。試行回数を、安全に、増やせる。これが「整えてから参入」がもたらす本当の強さです。

**注意：GO判定に「全勝」は要りません。** 探しているのは「全部当たる戦略」ではなく、「**1つの、確実に反応が取れる勝ち筋**」です。1点突破の穴が見つかれば、参入後に広げられます。

## 4. プロとの壁打ちで、成功にもう一歩近づける

GO判定が出た——おめでとうございます。でも、思い出してください。第2節で言ったとおり、**テストで「当たった」数字も、まだ100%ではありません。** ここに、最後の、そして最も費用対効果の高いリスク低減の一手があります。

**現場のマーケットをよく知るプロに、壁打ちしてもらうこと。**

考えてみてください。あなたはいま、第1講から第6講まで、他の誰よりも自分の事業を深く掘り下げてきました。テーマの一文、入口商品、ローカライズ、そして**実測データ付きの検証結果**まで揃っている。この状態は、ふつうの「ベトナムに興味があります」という相談者とは、まったく別次元です。

この**磨き上げた材料を持って**、現地の市場を肌で知っているプロに相談すると、何が起きるか。

- AIやテストでは拾いきれない「**現場の肌感**」で、あなたの勝ち筋を裏取りできる（「その価格帯、実はこの地区だと厳しいですよ」「その訴求、今の流行と合ってます」）
- 法人設立・条件付き業種・決済・現地パートナーといった実務の**落とし穴を、踏む前に**教えてもらえる
- 話が具体的なので、**相手も本気で答えられる**。「実測CPL付きで相談に来る人」は、プロから見ても応援したくなる相手です

逆に、何も準備せずに「ベトナムで何かやりたい」と相談しても、返ってくるのは一般論だけです。**このマニュアルをここまでやり切った価値は、プロとの壁打ちの質に直結します。** 同じ相談でも、話の進み方と、成功への近づき方が、まるで変わります。

そして——GOだけではありません。PIVOTやNO-GOで迷ったときこそ、プロの目は効きます。「この数字は本当にダメなのか、それとも見せ方の問題なのか」。自分とAIだけでは堂々巡りになる判断に、現場を知る第三者の視点が入ると、次の一手が見えてきます。

## 5. GOの後の実務——法人化・お金・決済

GO判定が出て、プロの壁打ちで裏も取れたら、初めて「虎に乗る」準備です。ここからは実務情報を駆け足で押さえます（詳細は付録A・B・C。**すべて目安であり、実行前に専門家への確認が必須**です。前節の無料相談も活用してください）。

### 法人化のタイミングと形態

検証が終わったいまが、法人化を検討する正しいタイミングです。主な選択肢：

| 形態 | 概要 | 向いているケース |
|------|------|----------------|
| 現地法人（外資100%） | ベトナムで正式に事業を行う基本形。IRC（投資登録証明書）→ERC（企業登録証明書）の順で取得 | 本格参入。飲食・小売・サービスの店舗営業 |
| 現地パートナーとの合弁 | 出資を分け合う。条件付き業種で必要になる場合も | 規制業種、現地網を借りたい場合 |
| 駐在員事務所 | 市場調査・連絡業務のみ。**営業行為・売上計上は不可** | 大企業の様子見向き。小規模参入には遠回り |
| 越境のまま（法人なし） | 日本からEC・ライセンス供与・研修販売等 | 物販・ノウハウ提供が主で現地拠点が不要な場合 |
| フランチャイズ／ライセンス | 現地事業者に運営を任せ、ブランドと仕組みを供与 | 自分が日本を離れられない場合の有力案 |

- 設立の所要期間：目安1〜3ヶ月（業種による。条件付き業種はさらに長い）
- 費用感：コンサル・代行込みで数十万円〜（業種・資本金要件で変動）
- 美容・教育・飲食・医療周辺は**条件付き業種**の規制に注意（付録A）

### 決済——お客さんからどうお金をもらうか

ベトナムの消費者の支払い手段は日本と大きく違います。

- **銀行QR（VietQR）・銀行振込**：都市部で最も日常的。個人間でも店でもQRスキャンが標準
- **MoMo・ZaloPay等の電子ウォレット**：若年〜中間層に浸透
- **COD（代金引換）**：ECではいまだに主要な選択肢。「モノを見てから払う」文化
- **クレジットカード**：普及率は低い。頼りにしない
- **現金**：依然として健在

実務上の含意：**「前払いのみ」は機会損失が大きい**市場です。予約金＋残額は当日QR、のような柔軟な設計が定石です。

### 採算シミュレーションの型

確定戦略書には、最低限この計算を入れます。

```
CPL（テスト実測値）×（登録→成約率の仮置き）= 顧客獲得単価（CAC）
入口商品の粗利 + 本命商品への転換率 × 本命商品の粗利 = 顧客生涯価値（LTV簡易版）
LTV ÷ CAC が 3倍以上 → 健全な入口。1〜3倍 → 転換率の改善が課題。1倍未満 → 価格か商品の再設計
```

テストの実測CPLを使えるのが、検証をやった者の特権です。「たぶん客は来るだろう」ではなく、「リスト1件◯◯VNDで取れることは実証済み」から始まる事業計画は、金融機関やパートナーへの説得力がまるで違います。

## 6. プロへの依頼書——丸投げしない外注の技術

GO判定後の広告運用は、デジタルマーケのプロ（現地代理店・フリーランス）に任せるのが基本です。あなたの時間は商品と品質に使うべきだからです。しかし、ここに最後の大きな罠があります。

**「良さそうな代理店に丸投げ」は、失敗パターン3（序章）の再来です。**

丸投げを防ぐ道具が**依頼書**です。検証フェーズを自分で回したあなたには、もう依頼書を書く材料がすべて揃っています。

### 依頼書に書く7項目

1. **事業の背景と目的**（テーマの一文＝第1講）
2. **商品と顧客**（入口商品設計書＝第2講、当たった訴求＝テスト結果）
3. **実証済みの勝ち筋**（どの広告が、どの数値で当たったか。クリエイティブ現物を添付）
4. **KPI**（何を、いくらで、何件。例：CPL◯◯VND以下でリスト月◯件）
5. **予算と期間**（月額広告費と運用費を分けて明示させる）
6. **役割分担**（後述）
7. **報告の形式と頻度**（週次で数字、月次で分析。数字の定義まで揃える）

### 役割分担の設計——自分がやること／プロに任せること

| 自分（経営者）がやること | プロに任せること |
|----------------------|----------------|
| 商品と体験の品質 | 広告の運用・入札・配信最適化 |
| 「100%約束できる結果」を守ること | クリエイティブの量産・差し替え |
| KPIの設定と、数字の意味を問うこと | ターゲティングの調整 |
| 顔出し・信頼の発信（あなた自身が資産） | レポーティング |
| 最終判断（続ける・変える・止める） | KOC・KOLのネットワークとキャスティング |

原則はひとつ：**「何を達成するか」は自分が決め、「どう達成するか」はプロに任せる。** 逆にしてはいけません。運用の手法に口を出しすぎるのも、KPIの設定まで任せるのも、どちらも失敗します。

### 相場観と地雷回避（目安。詳細は付録B）

- 運用代行費：月額広告費の15〜20%、または固定で月数万〜十数万円規模から
- 「フォロワー◯万人保証」「必ずバズらせます」を謳う業者は避ける（買ったフォロワーに意味はありません）
- 契約は**3ヶ月単位**から。年間契約の一括前払いは求められても応じない
- 広告アカウントの**管理者権限は必ず自社側が保持**する（第4講で自社に作った広告アカウントを使わせる形にする。解約時にアカウントごと失う事故が実際にあります）
- 探し方：日系の現地代理店／現地大手／フリーランス。それぞれの長短は付録Bに。**どの業者が信頼できるかの判断自体、前節の無料相談で壁打ちできます**

## 8. 佐藤さんの例

佐藤さんの6週間のテスト結果は、想定を1つ裏切りました。

- **テスト1（信頼の見せ方）**：本人顔出し動画がイメージ映像に**圧勝**（視聴完了率2.3倍、保存4倍）。コメントは「この先生は本物?」「ホーチミンのどこ?」という期待型が多数
- **テスト2（訴求軸）**：意外にも「銀座と同じ32手順」（本物訴求）と「VIP体験」訴求が僅差の引き分け。ただし**登録フォームの離脱が多い**という矛盾を発見 → フォームの項目が多すぎた（AIの分析指摘）
- **KOC**：4人中、フォロワー1.2万人のKOCの投稿だけが突出（保存800件超）。共通点は「自分の肌悩みを正直に書く」スタイル
- **想定外**：日本人コミュニティのグループ投稿から、**在越日本人の登録が想定の3倍**入った

**判定：🟢 GO。** 勝ち筋は「佐藤さん本人の顔出し×本物訴求×KOCの正直レビュー」。そして二段構え（第1講）の仮説どおり、**最初の売上は在越日本人から立てて、ベトナム人向けはKOC起点で育てる**戦略に確定。フォーム改善だけ追加で1サイクル回し、CPLは当初の6割まで下がりました。

**プロとの壁打ち**：佐藤さんはGO判定の後、いきなり法人設立には走りませんでした。実測データ一式を持って、現地の進出支援のプロに無料相談へ。そこで2つの収穫がありました。①「時間借りではなく、その提携サロン内に"店舗内店舗"として契約する形なら、条件付き業種の要件を軽くクリアできる」という実務の抜け道。②「在越日本人先行は正解。ただしベトナム人向けは、その地区だと想定価格が2割高い」という現場の肌感。テストだけではわからなかったこの2点で、佐藤さんの参入プランは一段固くなりました。

参入形態は「提携サロン内での営業から始めるため、まず小規模の現地法人＋提携契約」の方針に。依頼書はプロンプト⑬で作成し、現地の日系代理店とフリーランス2者に提示——「実測CPL付きの依頼書は初めて見た」と言われたそうです。

## 9. 第6講のまとめ

- データは**定量→定性→矛盾**の順に読む。矛盾こそ直すべき場所を教えてくれる
- **AIの「当たる」もテストの「当たった」も100%ではない**。検証の目的は確実に当てることではなく、**外したときの傷を致命傷にしない**こと
- **痛手は非対称**。オンラインの失敗はかすり傷、リアル先走りの失敗は大出血。NO-GOは第1講に戻る合図——安全に何度でも試せる
- GO判定に全勝は不要。**1つの確実な勝ち筋**があればいい
- **現場を知るプロとの壁打ち**で最終確認する。磨いた材料を持つほど話は進む（JS EVOLUTIONのLINE無料相談を活用）
- 法人化は検証後。プロには**丸投げせず依頼書で任せ**、広告アカウント権限は手放さない
