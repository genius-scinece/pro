# 虎の背に乗る前に — ベトナム市場参入・実践マニュアル（全7講）

**（仮タイトル。販売時に変更可）**

## このマニュアルについて

「ベトナム市場が良いと聞いている。すぐにでもビジネスを始めてみたい。でも、まず何をしたらいいかわからない」——そんな日本人経営者のための、**手を動かしながら事業設計書を完成させる**実践マニュアルです。

各講を終えるたびに成果物が1つ完成し、最後まで進むと「確定した戦略に基づく事業設計書」と「明日から動けるアクションリスト」が揃います。

## 構成と成果物

| 講 | タイトル | 終了時に完成するもの |

| 第2講 | 売る商品を1つ決める（入口商品設計） | 入口商品の設計書 |

## 制作メモ（販売時には削除）

- 形式：Markdown。note・Brain・Tips等にそのまま貼り付け可能。Word版（.docx）も同梱
- 分量：各講 約8,000〜13,000字、全体約13〜14万字
- 通し事例：架空の経営者「佐藤さん」（東京で美容サロン2店舗を経営）が全講に登場し、各講の成果物サンプルを提示
- AIプロンプト：全講にコピペで使えるプロンプト16本を収録（ChatGPT / Claude / Gemini いずれでも動作）
- 実務情報：第5講に「法人設立前に合法にできる範囲」、第6講に「法人化の判断・決済・依頼費用・プロとの壁打ち」、付録に詳細
- 第6講に「痛手の非対称性（オンライン失敗は軽傷／リアル先走りは重傷）」「NO-GOなら第1講へ戻る」「JS EVOLUTIONのLINE無料相談」を収録
- 第7講：Addnessを第一推奨としつつ、Notion／スプレッドシートでの汎用手順を併記
- 要挿入：第6講のCTAボックス内「［LINE友だち追加のQRコード／リンクをここに挿入］」に実際のQR/リンクを差し込む
