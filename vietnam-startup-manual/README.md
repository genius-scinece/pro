# 虎の背に乗る前に — ベトナム市場参入・実践マニュアル（全6講）

**（仮タイトル。販売時に変更可）**

## このマニュアルについて

「ベトナム市場が良いと聞いている。すぐにでもビジネスを始めてみたい。でも、まず何をしたらいいかわからない」——そんな日本人経営者のための、**手を動かしながら事業設計書を完成させる**実践マニュアルです。

各講を終えるたびに成果物が1つ完成し、最後まで進むと「確定した戦略に基づく事業設計書」と「明日から動けるアクションリスト」が揃います。

## 構成と成果物

| 講 | タイトル | 終了時に完成するもの |
|---|---------|-------------------|
| 序章 | このマニュアルの使い方・ベトナム市場を知る | ベトナム市場の全体像が頭に入る |
| 第1講 | やりたいテーマを絞る | テーマ設定シート（誰の・何を・どのジャンルで解くかの一文） |
| 第2講 | 売る商品を1つ決める（入口商品設計） | 入口商品の設計書 |
| 第3講 | ローカライズ設計（日本人向け vs ベトナム人向け） | ローカライズ設計シート（両市場向けの訴求） |
| 第4講 | デジタルマーケでリサーチする（ABテスト設計） | ABテスト設計書 |
| 第5講 | 当たる戦略を見つけて確定させる | 確定戦略書＋プロへの依頼書 |
| 第6講 | 全体をまとめてAIでファイル化 → Addnessへ | 事業設計書＋ゴール設定＋アクションリスト |
| 付録 | 法務・お金・決済・用語集 | 実務の参照資料 |

## 制作メモ（販売時には削除）

- 形式：Markdown。note・Brain・Tips等にそのまま貼り付け可能
- 分量：各講 約8,000〜12,000字、全体約7〜8万字
- 通し事例：架空の経営者「佐藤さん」（東京で美容サロン2店舗を経営）が全講に登場し、各講の成果物サンプルを提示
- AIプロンプト：全講にコピペで使えるプロンプトを収録（ChatGPT / Claude / Gemini いずれでも動作する書き方）
- 実務情報：第4講に「法人設立前に合法にできる範囲」、第5講に「法人化の判断・決済・依頼費用」、付録に詳細
- 第6講：Addnessを第一推奨としつつ、Notion／スプレッドシートでの汎用手順を併記
